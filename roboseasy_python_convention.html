모듈 / 패키지

NAMING
snake_case — 짧고 소문자, 하이픈(-) 사용 금지

모든 Python 파일명과 패키지명은 소문자 snake_case를 사용한다. 하이픈(-)은 임포트가 불가능하므로 절대 사용하지 않는다.

✓ GOOD
roboseasy_utils.py
state_estimator.py
joint_controller.py
ros2_sensor_bridge.py
✗ BAD
RoboseasyUtils.py   # PascalCase X
state-estimator.py  # 하이픈 X
StateEstimator.py   # PascalCase X
se.py               # 의미 없는 약어 X

NAMING

클래스는 PascalCase. 사용자 정의 예외 클래스는 반드시 Error로 끝나야 한다.

class JointLimitError(Exception):
    pass

class SensorTimeoutError(RuntimeError):
    pass
✗ BAD
class state_estimator:   # snake_case X
    pass

class jointcontroller:  # 소문자 X
    pass

# 예외 클래스
class JointLimit(Exception):  # Error 없음 X
    pass

class SensorException:  # Exception 접미사 X
    pass

Boolean 변수 ⭐

NAMING
반드시 is_ 또는 has_ 접두사로 시작

bool 타입 변수는 반드시 is_ 또는 has_ 접두사로 시작한다. 변수명만 보고도 True/False 값임을 즉시 인식할 수 있어야 한다.

is_
상태 / 조건 여부 — "~인가?"
has_
기능 / 데이터 보유 여부 — "~를 가졌는가?"
✓ GOOD
class StateEstimatorNode(Node):
    def __init__(self) -> None:
        self.is_active: bool = False
        self.is_initialized: bool = False
        self.is_foot_contact: bool = False
        self.has_velocity_data: bool = False
        self.has_imu_subscriber: bool = False

    def process(self) -> None:
        # 로컬 변수도 동일 규칙
        is_valid = not self._queue.empty()
        has_data = len(self._buffer) > 0
        if is_valid and has_data:
            self._update()
✗ BAD
class BadNode(Node):
    def __init__(self) -> None:
        self.active = False            # is_ 없음 X
        self.velocity_data = False    # has_ 없음 X
        self.bActive = True            # 헝가리안 b X
        self.foot_contact_flag = True  # flag 접미사 X
        self.check = True              # 의미 불명확 X
        self.status = False            # 타입 불분명 X
한 눈에 확인:  if is_foot_contact and has_velocity_data:  — 타입 선언 없이도 모두 bool임을 즉시 인식.

private / protected 멤버

NAMING
protected: 밑줄 1개(_) / private: 밑줄 2개(__)

외부에서 직접 접근하지 않아야 하는 멤버는 _로 시작한다. 서브클래스에서도 접근하면 안 되는 멤버는 __로 시작한다 (name mangling 적용).

✓ GOOD
class StateEstimatorNode(Node):
    def __init__(self) -> None:
        # protected — 서브클래스에서 접근 가능
        self._joint_names: list[str] = []
        self._control_time: float = 0.01
        self._is_initialized: bool = False

        # private — 외부/서브클래스 모두 접근 불가
        self.__callback_group = ReentrantCallbackGroup()
        self.__timer = None
Google Style 권고: Python에는 진정한 private이 없으므로 _single_underscore를 기본으로 사용하고, name mangling이 꼭 필요한 경우에만 __double을 사용한다.

Docstring — Google Style

DOCS
Args / Returns / Raises / Example 섹션 구조 사용

모든 public 모듈, 클래스, 함수에 Docstring을 작성한다. Google Style은 들여쓰기 기반의 섹션 구조를 사용한다. 한국어 작성을 허용한다.

✓ GOOD — Google Style Docstring
def calculate_dcm(
    com_pos: tuple[float, float],
    com_vel: tuple[float, float],
    omega: float,
) -> tuple[float, float]:
    """DCM (Divergent Component of Motion) 을 계산한다.

    LIPM 기반으로 발산 운동 성분을 계산하여 균형 제어에 사용한다.

    Args:
        com_pos: CoM 위치 (x, y) [m]
        com_vel: CoM 속도 (vx, vy) [m/s]
        omega: LIPM 고유 주파수 sqrt(g/h) [rad/s]

    Returns:
        DCM 위치 (xi_x, xi_y) [m] tuple 형태로 반환.

    Raises:
        ValueError: omega가 0 이하인 경우.

    Example:
        >>> dcm = calculate_dcm((0.0, 0.0), (0.1, 0.0), 3.13)
        >>> print(dcm)
        (0.031, 0.0)
    """
    if omega <= 0:
        raise ValueError(f'omega must be positive, got {omega}')
    xi_x = com_pos[0] + com_vel[0] / omega
    xi_y = com_pos[1] + com_vel[1] / omega
    return xi_x, xi_y
클래스 Docstring: 클래스 수준에서는 Attributes: 섹션으로 주요 멤버를 기술한다. __init__의 파라미터는 클래스 Docstring에 통합하거나 __init__에 별도 작성한다.

ROS2 Python 패턴은 위의 Python 네이밍 규칙을 따르되, ROS2 특유의 구조적 컨벤션을 추가로 적용한다.
ROS2
클래스명: PascalCase + Node 접미사 / Node 상속 / __init__ 구조화

ROS2 노드 클래스는 rclpy.node.Node를 상속하며, 클래스명은 기능을 설명하는 PascalCase + Node 접미사를 붙인다. __init__ 내부는 선언부 → 구독/발행 → 타이머 순서로 작성한다.

✓ ROS2 GOOD
from __future__ import annotations

import rclpy
from rclpy.node import Node
from sensor_msgs.msg import Imu, JointState
from roboseasy_msgs.msg import RobotState


class StateEstimatorNode(Node):  # PascalCase + Node
    """로봇 상태 추정 노드.

    IMU 및 관절 상태를 구독하여 로봇 상태를 추정하고 퍼블리시한다.
    """

    def __init__(self) -> None:
        super().__init__('state_estimator_node')

        # ── 1) 파라미터 선언 ──────────────────────────────
        self.declare_parameter('control_hz', 100)
        self._control_hz: int = (
            self.get_parameter('control_hz')
            .get_parameter_value()
            .integer_value
        )

        # ── 2) 내부 상태 변수 ─────────────────────────────
        self._is_initialized: bool = False
        self._has_imu_data: bool = False
        self._joint_names: list[str] = []

        # ── 3) Subscriber / Publisher ─────────────────────
        self._imu_sub = self.create_subscription(
            Imu,
            '/roboseasy/imu/data',
            self.imu_callback,
            10,
        )
        self._state_pub = self.create_publisher(
            RobotState,
            '/roboseasy/robot_state',
            10,
        )

        # ── 4) Timer ──────────────────────────────────────
        self._timer = self.create_timer(
            1.0 / self._control_hz,
            self.timer_callback,
        )

ROS2 노드의 진입점 main() 함수는 타입 힌트를 포함하고, try-finally로 노드 종료를 보장한다.

✓ ROS2 GOOD
def main(args: list[str] | None = None) -> None:
    """노드 진입점."""
    rclpy.init(args=args)
    node = StateEstimatorNode()

    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        node.get_logger().info('Keyboard interrupt, shutting down.')
    finally:
        node.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
